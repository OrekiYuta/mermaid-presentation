# Mermaid Presentation

Mermaid Presentation is a presentation tool that turns Mermaid code into diagrams with step-by-step playback support.

It is designed for real explanation and walkthrough scenarios, especially when you need to present a sequence diagram progressively instead of showing the whole result at once.

## Highlights

1. Perfect step-by-step presentation for sequence diagrams, making it much easier to explain a flow line by line.
2. Export the current diagram as SVG.

## Usage

- Directly open `index.html` in a browser, and you will see a sample presentation.
